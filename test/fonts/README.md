# Fontes dos testes

Roboto (regular, medium e bold), copiada do SDK do Flutter, usada **só nos
testes** no lugar da Inter (as métricas são parecidas). Fica no repositório
para os testes de layout funcionarem igual em qualquer máquina, inclusive no
GitHub Actions, sem rede e sem depender de onde o SDK está instalado.

Licença: Apache 2.0 (ver `LICENSE-roboto.txt`). O app em si continua usando a
Inter via `google_fonts`.
